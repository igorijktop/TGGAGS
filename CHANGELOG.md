# Changelog

## 1.1.0

- **Conversation in the main window.** The chat is now the main window itself (permanent *Chat* tab); the side chat is optional (`Ctrl+Alt+B`).
- **Update button.** The app checks for a newer version and shows an **Update** button in the title bar. One click downloads the installer (checksum-verified) and installs it, then restarts the app. *Settings → About* has *Check for updates* and an automatic-check switch.
- **Image models.** Models can now be added as *Text* or *Image* for every provider (the type is guessed from the model ID), and switched later.

## 1.0.0

- First release: editor, coding agents, terminal, Git, debugger, MCP, image studio and the offline Windows installer.
